
# 🛠️ Backend Project Setup Instructions (Kotlin + Spring Boot)

## 1. 프로젝트 개요 & 기술 스택
- **프로젝트 명:** PT Class First-Come-First-Served Reservation & Fitness App (Fitness Platform)
- **언어:** Kotlin (JDK 21 권장, 최신 LTS)
- **프레임워크:** Spring Boot 3.x
- **빌드 도구:** Gradle (Kotlin DSL - `build.gradle.kts`)
- **데이터베이스:** MySQL 8.x (JPA / QueryDSL)
- **인메모리/캐시:** Redis (Spring Data Redis / Redisson)
- **메시지 큐:** Apache Kafka (Spring for Apache Kafka)
- **테스트 & 관측:** JUnit5, Mockk, k6, Prometheus, Micrometer

---

## 2. 프로젝트 뼈대 생성 및 필수 의존성 (Dependencies)

Claude Code는 아래 필수 의존성(Dependencies)을 포함하여 Spring Boot 프로젝트 뼈대를 생성하거나 `build.gradle.kts`를 작성한다.

```kotlin
plugins {
    id("org.springframework.boot") version "3.3.3" // 또는 3.x 최신버전
    id("io.spring.dependency-management") version "1.1.6"
    kotlin("jvm") version "1.9.25"
    kotlin("plugin.spring") version "1.9.25"
    kotlin("plugin.jpa") version "1.9.25"
    kotlin("kapt") version "1.9.25"
}

group = "com.fitness"
version = "0.0.1-SNAPSHOT"
java.sourceCompatibility = JavaVersion.VERSION_21

repositories {
    mavenCentral()
}

dependencies {
    // Spring Boot Core
    implementation("org.springframework.boot:spring-boot-starter-web")
    implementation("org.springframework.boot:spring-boot-starter-validation")
    implementation("com.fasterxml.jackson.module:fasterxml.jackson-module-kotlin")
    implementation("org.jetbrains.kotlin:kotlin-reflect")

    // Database & JPA
    implementation("org.springframework.boot:spring-boot-starter-data-jpa")
    runtimeOnly("com.mysql:mysql-connector-j")

    // Redis (Caching & Lock & Lua Script)
    implementation("org.springframework.boot:spring-boot-starter-data-redis")
    implementation("org.redisson:redisson-spring-boot-starter:3.34.0")

    // Kafka (Messaging)
    implementation("org.springframework.kafka:spring-kafka")

    // Actuator & Observability (Prometheus)
    implementation("org.springframework.boot:spring-boot-starter-actuator")
    implementation("io.micrometer:micrometer-registry-prometheus")

    // Test
    testImplementation("org.springframework.boot:spring-boot-starter-test")
    testImplementation("org.springframework.kafka:spring-kafka-test")
    testImplementation("io.mockk:mockk:1.13.12")
    testImplementation("com.ninja-squad:spring-mockk:4.0.2")
}
